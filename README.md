# สวัสดิการวัยเก๋า เข้าใจง่าย

ระบบทำคลิปยูทูบบน GitHub ฟรี รันบนคลาวด์ ไม่ต้องเปิดเครื่องเพื่อเรนเดอร์

ช่อง: https://www.youtube.com/channel/UC5Y9nTVK73bOLlNgrxY0Kng

คลิปยาวประมาณ 12–15 นาที บทภาษาไทยโทนอธิบายให้คนในบ้านฟัง เสียงไทยผู้หญิง (Premwadee) สร้างด้วย text-to-speech ตัวเลขในบทยึดแหล่งหน่วยงานรัฐ และระบบจะไม่ยอมรับบทที่มีจำนวนเงินนอกแฟ้มข้อเท็จจริง

ข้อมูลในชุดแรกคือ **15 พฤศจิกายน 2569** หลังตั้งคีย์ยูทูบแล้ว ระบบอัปเป็นคลิปส่วนตัวแล้วตั้งเวลาให้ **เผยแพร่อัตโนมัติตอน 18:00 ตามไทย** (คลิปสั้นตามหลัง 2 ชั่วโมง) บนวันอาทิตย์ อังคาร พฤหัสบดี เสาร์

## คลิปชุดแรก

1. เบี้ยยังชีพผู้สูงอายุ พ.ย. 2569 ได้เท่าไร เงินเข้าวันไหน
2. บัตรสวัสดิการแห่งรัฐ พ.ย. 2569 เงินสดถอนได้ไหม
3. ลงทะเบียนเบี้ยผู้สูงอายุ ไปไหน ใช้เอกสารอะไร
4. ข่าวเงินเข้าผู้สูงอายุ เช็กยังไงว่าจริง กันมิจฉาชีพ

ทุกบทบอกชัดว่าช่องนี้ไม่ใช่หน่วยงานรัฐ ไม่ขอเลขบัตร ไม่ขอรหัส และไม่มีทางให้โอนเงิน

## ทำครั้งเดียว แล้วสั่งงานจากมือถือ

1. สมัคร GitHub ฟรีที่ https://github.com
2. สร้าง repository ใหม่ ตั้งเป็น **Public** เพื่อให้เวลาของ GitHub Actions ฟรี
3. อัปโหลดโฟลเดอร์นี้ขึ้น repository ให้ครบ ทั้ง `.github`, `src`, `topics`, `facts`, `assets`, `state`
4. เปิดแท็บ **Actions** แล้วกดเปิดใช้ workflow ถ้า GitHub ถาม
5. เลือก **Make video** แล้วกด **Run workflow**
   - ช่อง topic ใส่ `next` เพื่อทำคลิปถัดไปในคิว
   - หรือใส่รหัส เช่น `001-bai-yang-cheep-nov`
6. รอประมาณ 20–40 นาที
7. เปิดรันนั้นแล้วดาวน์โหลด artifact ชื่อ `video-...`
8. ในไฟล์มี `video.mp4`, `thumbnail.jpg`, `description.txt`, `captions.srt`, `pinned-comment.txt`
9. อัปคลิปในแอป YouTube วางคำอธิบายจากไฟล์ แล้วตรวจตัวเลขกับวันที่บนจอก่อนกดเผยแพร่

ตารางอัตโนมัติ (หลังมีคีย์ยูทูบ):
1. **อาทิตย์ อังคาร พฤหัสบดี เสาร์** เวลา **16:00 ตามไทย** GitHub เริ่มทำคลิปเต็ม + คลิปสั้น
2. อัปขึ้นช่องเป็นส่วนตัว แล้วตั้ง `publishAt` ให้ **คลิปยาวเปิดสาธารณะ 18:00** และ **คลิปสั้น 20:00** วันเดียวกัน
3. ยูทูบเป็นคนกดเผยแพร่เองเมื่อถึงเวลา ไม่ต้องเปิดแล็ปท็อป

ถ้าข้อมูลในบทเก่ากว่า 20 วัน ระบบจะอัปเป็นส่วนตัวโดยไม่ตั้งเวลา เพื่อให้ตรวจตัวเลขก่อน เปลี่ยนวัน/เวลาได้ใน `channel.json` ส่วน `publish` และใน `.github/workflows/make-video.yml`

## ให้อัปเข้าช่องเอง และเผยแพร่ตอน 18:00 อัตโนมัติ

ทำบนเบราว์เซอร์ได้ ไม่จำเป็นต้องเปิดโปรแกรมบนเครื่อง

1. เข้า Google Cloud Console แล้วสร้างโปรเจกต์
2. เปิดใช้ **YouTube Data API v3**
3. ตั้ง OAuth consent screen เป็น External แล้วเพิ่มอีเมลของช่องเป็น test user
4. สร้าง OAuth client ชนิด Desktop แล้วจด Client ID กับ Client secret
5. เปิด https://developers.google.com/oauthplayground
6. กดรูปเฟือง มาร์ก Use your own OAuth credentials แล้วใส่ client ของตัวเอง
7. เลือกสโคป `https://www.googleapis.com/auth/youtube.upload` แล้วกด Authorize
8. กด Exchange authorization code for tokens แล้วคัดลอก refresh token
9. ใน repository เปิด **Settings > Secrets and variables > Actions** แล้วสร้างสามค่า
   - `YOUTUBE_CLIENT_ID`
   - `YOUTUBE_CLIENT_SECRET`
   - `YOUTUBE_REFRESH_TOKEN`
10. รัน workflow อีกครั้ง ระบบอัปเป็นส่วนตัวแล้วตั้งเวลา **18:00 / 20:00 ตามไทย** ให้เปิดสาธารณะเอง

ใน Studio จะเห็นสถานะเป็น Scheduled จนถึงเวลาที่ตั้งไว้ ภาพปกถูกตั้งให้เมื่อช่องยืนยันตัวตนแล้ว ถ้าตั้งไม่ได้ ใช้ `thumbnail.jpg` ใน artifact

## บทใหม่หลังสี่คลิปแรก

ใน `facts/topic_bank.json` มีหัวข้อสำรองอีกหกเรื่อง เช่น ย้ายทะเบียนบ้าน เงินไม่เข้า และค่าไฟเกินเพดาน

ถ้าต้องการให้ระบบร่างบทต่อเมื่อคิวหมด ให้สร้าง secret ชื่อ `GEMINI_API_KEY` จาก Google AI Studio แล้วตอนกดรัน workflow ให้ติ๊ก **generate_if_empty**

บทที่ร่างเองต้องผ่านเกณฑ์เดียวกับบทที่เขียนไว้ คือห้ามมีจำนวนเงินนอก `facts/benefits.json` ต้องมีประโยคว่าไม่ใช่หน่วยงานรัฐ และต้องบอกให้สอบถามหน่วยงานในพื้นที่ ถ้าไม่ผ่าน ระบบจะไม่เรนเดอร์

## เมื่อตัวเลขราชการเปลี่ยน

1. แก้ `facts/benefits.json`
2. แก้บทใน `topics/scripts/` ให้ตรงกัน
3. เปลี่ยน `as_of` กับ `as_of_iso`
4. รัน workflow โดยใส่รหัสบทนั้นอีกครั้ง

ถ้าหน้าเว็บราชการยังเปิดได้และตัวเลขที่บทใช้อยู่หายไปจากหน้านั้น ระบบจะหยุดเองเพื่อไม่ให้คลิปเก่ายังถูกสร้างต่อ ถ้าเว็บนั้นบล็อกเครื่องของ GitHub ระบบจะเตือนแล้วยังเรนเดอร์ต่อ เพราะบทถูกตรวจไว้แล้ว แต่คลิปยังเป็นส่วนตัว จนกว่าจะตรวจเอง

## ตัวอักษรและเสียง

หัวข้อและตัวเลขใช้ **Kanit** ตัวหนา ข้อความยาวใช้ **Sarabun** ตัวหนา ทั้งคู่เป็นฟอนต์ OFL ตัวบนจอใหญ่กว่าเดิม เพื่อให้อ่านบนทีวีได้โดยไม่ต้องเพ่ง พื้นเป็นสีครีมอุ่น ตัวอักษรเกือบดำ แถบหัวเป็นเขียวเข้ม แถบทองเข้มขึ้นเพื่อให้ยังเห็นเมื่อเลนส์ตาเหลือง ไม่ใช้ตัวเทาบาง และไม่ใช้สีแดงกับเขียวเป็นตัวแยกความหมาย

โลโก้คู่สูงอายุบนม้านั่งอยู่ใน `assets/brand/logo.jpg` เปิดคลิปและปิดคลิปมีโลโก้ค่อย ๆ ขยายเข้า พร้อมชื่อช่องตัวใหญ่ ระหว่างเนื้อหามีโลโก้เล็กมุมซ้ายบนขยับช้า ๆ เสียงประกอบเป็นเสียงเคาะและกระดิ่งสั้นที่สังเคราะห์เอง ได้ยินเฉพาะตอนเปิด ปิด และช่องว่างระหว่างประโยค ไม่กลบเสียงพูด ถ้าจะเปลี่ยนโลโก้ ให้วางไฟล์ใหม่ทับชื่อเดิม

## ชุดอัปโหลดและบันทึกคลิปที่ทำแล้ว

หลังเรนเดอร์ โฟลเดอร์ `out/package/` มีทุกอย่างที่ต้องใช้ตอนอัป: `title.txt` `title-options.txt` (ชื่อสำรองสำหรับ Test & compare) `description.txt` `tags.txt` `hashtags.txt` `pinned-comment.txt` `thumbnail.jpg` `captions.srt` และ `YOUTUBE-STUDIO-STEPS.md` ไฟล์เดียวที่เรียงทุกช่องตามลำดับหน้าจอ YouTube Studio พร้อมข้อความให้คัดลอกวางทีละขั้น ตั้งแต่ชื่อคลิป คำอธิบาย ภาพปก ไปจนถึงคลิปสั้นและสิ่งที่ต้องทำใน 48 ชั่วโมงแรก สำเนาของแต่ละคลิปเก็บไว้ถาวรใน `state/kits/` แท็กและแฮชแท็กของแต่ละเรื่องแก้ได้ใน `topics/seo.json`

คลิปที่ทำแล้วถูกบันทึกใน `state/published.json` และสรุปเป็นตารางอ่านง่ายใน `state/VIDEOS.md` ระบบจะข้ามเรื่องที่อยู่ในบันทึกเมื่อเลือกคลิปถัดไป

ทุกคลิปเต็มได้คลิปสั้นคู่กันใน `out/package/short/` เป็นภาพแนวตั้ง 1080×1920 ยาวราวหนึ่งนาที ยูทูบจึงนับเป็น Shorts คลิปสั้นหยิบไฮไลต์จากจอของคลิปเต็ม ไม่แต่งตัวเลขใหม่ แล้วชวนกดติดตามและเปิดคลิปเต็มจากลิงก์ในคำอธิบาย ถ้าอัปขึ้นช่อง คลิปสั้นจะใส่ลิงก์ของคลิปเต็มที่เพิ่งอัป ถ้ายังไม่อัป จะใส่ลิงก์ช่องแทน

เสียงคือ **Premwadee** (`th-TH-PremwadeeNeural`) เสียงไทยประสาทสังเคราะห์ที่ใช้กันแพร่หลาย ความเร็วช้าลงร้อยละ 10 ระดับเสียงต่ำลง 1 เฮิรตซ์ เสียงนี้ไม่ใช่เสียงของบุคคลจริง และระบบไม่เลียนเสียงนักข่าว ผู้ประกาศ หรือคนมีชื่อเสียง

ช่องนี้อธิบายประกาศสาธารณะเรื่องสิทธิการเงินของผู้สูงอายุ กฎ YouTube Partner Program ไม่ให้สร้างตัวละครเอไอมาสวมเป็นผู้เชี่ยวชาญการเงิน สุขภาพ กฎหมาย หรือการเมือง แล้วให้คำแนะนำส่วนตัว ดังนั้นทุกคลิปพูดชัดว่าเป็นเสียงสังเคราะห์ และไม่ใช่คำแนะนำการเงินส่วนตัว เวลาอัปขึ้นช่อง ระบบตั้ง `containsSyntheticMedia` เพื่อเปิดป้ายเนื้อหาสังเคราะห์ตามนโยบายของยูทูบ

ชื่อคลิปต้องตรงกับสิ่งที่คลิปพูดจริง ไม่ใช้คำว่าเงินเข้าทุกคนทั้งที่ขั้นอายุได้ไม่เท่ากัน เพราะชื่อที่หลอกผู้ชมขัดทั้งแนวชุมชนและกฎรายได้ของยูทูบ

ถ้าบริการเสียงหลักขัดข้อง ระบบจะลองโฮสต์สำรอง แล้วจึงตกไปใช้เสียงไทยอีกแบบที่ฟังกระด้างกว่า และจะเขียนกำกับไว้ในคำอธิบายคลิป

ตรวจบทโดยไม่สร้างวิดีโอ:

```bash
python -m src.make_video --check --topic next
```
