B. ONE-TIME: PUT THE PROJECT ON GITHUB (free)
============================================================
[ ] 1. Create a free GitHub account: https://github.com
[ ] 2. Create a new repository named e.g. somchai-thai-channel
[ ] 3. Set the repository to PUBLIC (needed for free Actions minutes)
[ ] 4. On this PC, open PowerShell and run (replace YOUR_USERNAME):

       cd d:\somchai-thai-channel
       git init
       git add .
       git commit -m "Add Thai welfare video autopilot"
       git branch -M main
       git remote add origin https://github.com/YOUR_USERNAME/somchai-thai-channel.git
       git push -u origin main

[ ] 5. Open the repo on GitHub → Actions → enable workflows if asked
[ ] 6. Confirm you see the workflow named "Make video"


============================================================
C. ONE-TIME: CONNECT YOUTUBE (so GitHub can upload)
============================================================
[ ] 7. Open Google Cloud Console: https://console.cloud.google.com/
[ ] 8. Create a project (any name)
[ ] 9. Enable API: YouTube Data API v3
[ ] 10. OAuth consent screen → External → add your channel Google email as Test user
[ ] 11. Create OAuth client → Application type: Desktop → save Client ID and Client Secret
[ ] 12. Open OAuth Playground: https://developers.google.com/oauthplayground
[ ] 13. Click the gear → tick "Use your own OAuth credentials" → paste Client ID + Secret
[ ] 14. In the left list, choose scope:
        https://www.googleapis.com/auth/youtube.upload
[ ] 15. Authorize → sign in with the Google account that owns the channel
[ ] 16. Click "Exchange authorization code for tokens"
[ ] 17. Copy the Refresh token (long string)

[ ] 18. In GitHub repo → Settings → Secrets and variables → Actions → New repository secret
        Add these three secrets exactly:

        Name: YOUTUBE_CLIENT_ID
        Value: (Client ID from step 11)

        Name: YOUTUBE_CLIENT_SECRET
        Value: (Client Secret from step 11)

        Name: YOUTUBE_REFRESH_TOKEN
        Value: (Refresh token from step 17)

[ ] 19. (Recommended) Verify the channel for custom thumbnails:
        https://www.youtube.com/verify
